# Цифровой мастер

Русскоязычное личное портфолио. Avadas представлен как прототип; схема на странице не является скриншотом приложения.

## Локальный запуск

Требуется Node.js 22 или новее. В папке `site` выполните `npm start` и откройте http://127.0.0.1:4173.
Зависимости устанавливать не требуется. Сервер привязан к loopback, а не к внешнему интерфейсу.

Проверки: `npm test` и `node --check public/app.js`.

## Состояние выпуска

Это локальный предпросмотр. Настоящие имя, контакты и скриншоты пока не предоставлены. Прием обращений отключен по умолчанию; форма явно сообщает об этом и не отправляет данные.

Перед публичным запуском нужны реальные реквизиты, согласованные условия и сведения об обработке обращений, способ получения заявок владельцем и проверка развертывания. В текущем сервере файл обращения сохраняется в `site/data`, доступ через HTTP запрещен. Эта папка и `.env` исключены из Git. Данные локальных тестов создаются во временной директории и удаляются.

После подготовки обработки прием локального сервера можно включить переменными `INTAKE_ENABLED=true` и `OWNER_CONTACT` с настоящим контактом. Сам по себе `OWNER_CONTACT` не настраивает отправку уведомлений: владелец должен организовать закрытый доступ к сохраненным обращениям. Не включать прием до выполнения этих условий. Сохранение рассчитано на один процесс Node; для масштабирования нужен общий транзакционный store.

## Обновление

- Тексты и схема: `public/index.html`.
- Внешний вид: `public/styles.css`.
- Меню, форма, выбор направления: `public/app.js`.
- HTTP/API: `server.mjs`; валидация и запись: `lib/inquiries.mjs`.
- Исследование, ТЗ и план: в корне проекта и `docs/superpowers`.

Шрифты запрашиваются у Google Fonts; при отсутствии сети используются системные. Для независимого публичного выпуска желательно разместить лицензированные WOFF2 локально и обновить CSP.


## Интерактивная демонстрация
Форма на странице работает только локально и не вызывает серверный API. Подтверждение демонстрационное. Для автономного HTML запустите `node scripts/build-standalone.mjs`; результат — `site/portfolio.html`. Проверки и ограничения: `INTERACTION-REPORT.md`.
