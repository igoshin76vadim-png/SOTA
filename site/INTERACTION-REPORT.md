# Проверка интерактивных элементов

Дата: 5 ноября 2026.

- Добавлена плавающая кнопка «Наверх»: появляется после 500 px прокрутки, ведёт к первому экрану и скрывается наверху. Проверено кликом.
- Форма: имя, email, сообщение, необязательное направление. Нативная проверка обязательных полей и email; визуальное подтверждение с анимированной галочкой. Заполнение и подтверждение проверены в браузере. Данные не отправляются и не сохраняются. Без JavaScript кнопка отключена.
- Счётчики: 1 прототип, 3 направления, 5 этапов. Анимируются однократно при появлении; итоговые значения проверены.
- Гамбургер: раскрытие, переход по ссылке и закрытие проверены. Также предусмотрены Escape и закрытие при переходе к широкому экрану.
- Учитываются prefers-reduced-motion и существующий переключатель анимаций.
- Фактическая мобильная область браузера: 375 px; горизонтального переполнения нет. Проверены меню, форма, возврат наверх. Изменение размера через инструмент не изменило фактическую ширину, поэтому широкую версию в этой проверке не подтверждаем. Это проверка в браузере, не на физических телефонах.
- node --test: 9 из 9 серверных тестов успешно. Эти тесты проверяют сервер, новые визуальные сценарии проверены вручную.

## Автономный файл

portfolio.html содержит CSS, JavaScript и SVG внутри файла, без внешних шрифтов и запросов fetch. Размер около 53 КБ. Генерация: node scripts/build-standalone.mjs. Синтаксис встроенного JavaScript проверен.

Открытие file:// в автоматизированном браузере заблокировано политикой инструмента (разрешены только HTTP/HTTPS), поэтому непосредственный запуск файла не проверен. HTML нужно сохранить из мессенджера и открыть браузером. Некоторые мессенджеры блокируют HTML или отключают JavaScript в предпросмотре: гарантировать запуск из любого мессенджера нельзя.
